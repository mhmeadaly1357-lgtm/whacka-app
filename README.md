# Whacka App

Whacka is a voice-notes and emotional AI companion app built with Flutter.

## Features
- Voice-to-text note recording
- Search and organize notes
- Firebase storage and data sync
- Emotional AI support via OpenAI-compatible API
- Responsive dark-themed mobile UI

## Stack
- Flutter
- Firebase
- Speech-to-Text
- OpenAI-compatible API

## Setup
1. Install Flutter SDK.
2. Run:
   ```bash
   flutter pub get
   ```
3. Configure Firebase:
   ```bash
   flutterfire configure
   ```
4. Replace the temporary Firebase credentials in `lib/firebase_options.dart`.
5. Run the app:
   ```bash
   flutter run
   ```

## Notes
This repository is an MVP starter scaffold for the product idea and can be expanded with authentication, note editing, audio attachments, and deployment workflows.
